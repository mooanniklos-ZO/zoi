# برنامجي المحاسبي لعيادة الأسنان - د. مالك الرميمة (Android Native)

تطبيق أندرويد متكامل بلغة **Kotlin** وواجهات **Jetpack Compose** لإدارة المالية والنظام المحاسبي لعيادة الأسنان للدكتور مالك الرميمة.

## المميزات الرئيسية
- 📊 **لوحة التحكم المالي**: نظرة عامة على المقبوضات النقدية، تكاليف المعامل، المستلزمات، الخرجيات، وديون المرضى مع حساب الصافي المالي بالخزينة تلقائياً.
- 💵 **حركة الدخل اليومي والمرضى**: متابعة زيارات وعلاجات المرضى، التشخيص، المبالغ الواصلة والمتبقية، وخيارات الاتصال المباشر والواتساب.
- 🧪 **معامل الأسنان**: متابعة شغل المعامل (زيركون، سيراميك، أطقم)، حالات التصنيع، التواريخ، ومستحقات المعامل.
- 📦 **مستلزمات ومواد الأسنان**: إدارة فواتير الشركات ومحلات المواد والمستلزمات الطبية والمدفوعات المتبقية.
- 💸 **الخرجيات والمصاريف اليومية**: تسجيل وتصنيف المصاريف التشغيلية (الممرضة، المطبخ، الأسرة، النثريات، وبترول وصيانة المولد).
- 📱 **أقساط وديون المرضى والرسائل التلقائية**: متابعة الديون، اسم الضامن/المعرف، وإرسال تذكيرات تلقائية عبر SMS وWhatsApp بنقرة واحدة.
- 📒 **الحسابات الشخصية**: جدول القيود الحسابية الخاصة (له / عليه / المتبقي).
- 📋 **الجرد العام والتدقيق المالي الدوري**: تقرير مالي شامل واستخراج كشف حساب مالي دوري قابل للمعاينة والطباعة.
- 🤖 **مساعد العيادة الذكي**: مساعد مالي تفاعلي لتحليل البيانات واستخراج التقارير النصية.
- 💾 **حفظ البيانات المباشر (Room Database)**: تخزين محلي آمن وموثوق لكافة البيانات على الجهاز.
